# Skill: Visual Fidelity Standard

This skill encapsulates rules for matching Airbnb's visual identity with pixel precision.

## Key Visual Rules
1. **Typography**:
   - Title: `26px / 1.2`, weight `600`, `#222222`.
   - Section Headings: `22px / 1.25`, weight `600`, `#222222`.
   - Body Text: `16px / 1.5`, weight `400` or `500`, `#222222`.
   - Muted/Subtext: `14px / 1.4`, weight `400`, `#717171`.
2. **Colors**:
   - Primary Airbnb Brand: `#FF385C`
   - Gradient CTA: `linear-gradient(90deg, #E61E4F 0%, #E31C5F 50%, #D70466 100%)`
   - Primary Text: `#222222`
   - Secondary Text: `#717171`
   - Light Gray Bg: `#F7F7F7`
   - Borders: `#DDDDDD` / `#EBEBEB`
3. **Elevations & Shadows**:
   - Card Shadow: `0 6px 16px rgba(0, 0, 0, 0.12)`
   - Hover Pill Shadow: `0 2px 4px rgba(0, 0, 0, 0.18)`
   - Active Dropdown Shadow: `0 4px 20px rgba(0, 0, 0, 0.15)`
